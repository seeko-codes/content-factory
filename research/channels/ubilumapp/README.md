# Ubilum / @ubilumapp

A separate, high-detail reference for the light-page mathematical animation format. Current Instagram audience: **32,100 followers**, observed October 29, 2026. The accessible 12-tile grid included a rounded **1M-view Calculus III reel**, about **31.15x** the current audience. This is observed reach, not an upload-time audience comparison or causal claim. A login gate prevented a complete channel ranking.

Start with [STYLE.md](STYLE.md), then open the particular construction audit below. The full former Ubilum research is retained here rather than compressed into the channel index: fifteen local recordings, fourteen named constructions, 356 sampled frames and 37 inspected contact sheets. A duplicate Calculus II recording is not counted as a new construction; the incidental exponential fragment is not a fully reviewed video.
