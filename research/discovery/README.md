# Wider creator discovery, outside the active gallery

The current reference set is [seven shortform math-animation creators](../channels/README.md). This directory preserves the broader creator-by-creator research without promoting it to an approved style reference. Some folders contain detailed frame reviews; others contain only metadata or unresolved leads. Open their scope and eligibility notes before using them. A completed analysis can remain useful even when its format falls outside this project brief.

Excluded formats include talking heads, handwriting, live coding, general science, live demonstrations and longform-only work. Some mathematical animation here is good but outside the final shortform shortlist. Do not describe all excluded creators as non-animation. The selection changed; their original evidence remains intact.

Original discovery registers remain separate: [math](../discovery-math.md) / [CSV](../discovery-math.csv), [science/animation](../discovery-science.md) / [CSV](../discovery-science.csv), and [shortform leads](../discovery-shortform.md) / [CSV](../discovery-shortform.csv). Their old eligibility vocabulary records the discovery pass, not final active membership. The definitive active membership is the channel-gallery index.
