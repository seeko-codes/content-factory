01 / An agent arrives without this conversation

Logic first. Then the right channel.

AGENTS.md instructs the agent to read root-level LOGIC.md first. The principles live in that file. From them, the agent proposes the intended viewer experience for your approval, then selects the relevant channel and loads its detailed clip research. CLAUDE.md points to the same entry instructions.

Read the exact clip dossier, reconstruction, visual states, source evidence and limits inside that channel. Preserve the depth. Model a specific inspected execution before varying it.

Your decision / Video intent

The agent brings you a recommendation: audience, problem, intended understanding, promise/payoff and likely channel reference. A batch proposal includes its count, formats and planned variations.

You say yes, no or suggest changes. Production starts within the approved scope. Material changes return to you; approval can cover a whole batch.

Your decision / Learning conclusions

The reviewer brings you the conclusion, supporting posts and uncertainty, plus the exact before/after edit and target file. Backpass prepares proposals using its real workflow.

You accept, reject or revise each change. Only approved edits are applied. The agent routes them to the appropriate guidance file and verifies them in future outputs.

Apply the output bar and working commands alongside this route. QUALITY.md defines the finished-video standard, STYLE.md the series identity, and README.md the execution commands. The campaign strategy defines the SAT audience and baseline-first approach; the research index supplies the candidate slate.

Another harness must load the entry instructions too. On this Mac, agents can reuse the configured Zernio connection and installed backpass tool. A checkout on another machine needs its own tools and credentials.

Team / Model allocation

Parallel production. Independent judgment.

Sol or Opus workers make the videos. Fable or Astra reviews the finished work and studies which compliant executions worked, which did not, and why. These are the owner’s preferred roles; actual model IDs depend on the harness.

Sol / Opus

Parallel production from complete briefs and source recipes. Each worker owns its video folder and returns a playable export. One integration owner handles shared code and registration.

Fable / Astra

Inspect each export independently. Later, watch winners and losers alongside eligible metrics, explain possible causes and propose fresh tests. Failed execution stays outside creative-rule comparisons.

Backpass

The real tool reads evidence-bearing review sessions and proposes guidance changes. You review the conclusions and exact edits; agents apply approved changes, then verify them in future exports.

Production is on hold at your request. This clarifies the workflow only. No batch or production workers have been launched.

This session exposes Sol and Astra. Use Opus or Fable when the harness actually exposes them; record the actual model and reasoning effort at dispatch. The reviewer choice does not itself configure backpass’s internal models.

    03 / Why the learning data stays interpretable

    Did the video actually test the rule?

    A low-performing compliant video can inform the creative hypothesis. A low-performing video that ignored the instruction is an execution failure. Both results are kept; they enter different analyses.

    A new rule changes future checks.

    Suppose you say, “Remove the completed step’s labels before the next step starts.” The agent records it in the appropriate standard, changes the video, renders again and inspects the handoffs in the actual export.

    1Feedback enters QUALITY.md, STYLE.md, the campaign guide or a narrower brief.
    2The changed source invalidates an earlier release review.
    3A fresh packet starts unverified. Evidence must establish the revised output.

    A published result keeps its context.

    Yesterday’s video stays linked to yesterday’s export and standards snapshot. Adding a new rule today does not retroactively make that execution noncompliant.

    Compare similar post ages, recipes and distribution modes, and keep rule versions visible. Corrupted or missing review evidence removes eligibility. Cumulative snapshots are repeated observations of a post, not independent experiments.

    The current learning export retains the 13 historical posts but excludes all 13: none has a linked compliance review.

    Backpass proposes. You decide what changes. The Fable/Astra review agent must first load eligible metrics, examine the corresponding videos, compare concrete post IDs and discuss possible explanations. The actual backpass CLI reads those sessions and proposes edits to research/instagram-strategy.md; the agent presents the conclusions, supporting evidence and exact proposed edits to you. After your decision, it applies only approved edits through the native workflow and routes any approved change to another file explicitly. It does not fetch Instagram data or directly optimize a numerical view count.

    Before the app exists, inspect reach, attention, audience growth and SAT-relevant responses. Future app activation and conversion are not measurable yet.

    04 / What happens automatically, and what does not

    The tools enforce boundaries. The agent runs the workflow.

    Implemented in code

    Mechanical execution

    • Save recordings, retain raw takes and align accepted narration locally.
    • Render the authored video through Remotion.
    • Freeze exports, standards and evidence; check review completeness and integrity.
    • Block publishing on failed, incomplete or stale reviews through the gated command.
    • Upload through Zernio, attach creative hashes, check live quota for sends and block ambiguous retries.
    • Separate eligible metrics from excluded outcomes.
    Agent responsibility

    Judgment + progression

    • Read LOGIC.md, propose video intent for your approval, then select a channel and exact clip.
    • Write a source-specific recipe, useful SAT brief, checked reasoning and animation.
    • Inspect the export, record truthful observations and leave unsupported checks unverified.
    • Fix the work, re-render and obtain a fresh review when needed.
    • Confirm post identity, collect metrics, analyze cohorts and run actual backpass.
    • Present learning conclusions and exact edits to you; apply approved guidance and test it on fresh examples.
    Your input

    Voice + direction

    • Record your voice using the local script-and-record-button page.
    • Approve or revise video intent and batch scope before production.
    • Accept, reject or revise learning conclusions and proposed guidance edits before application.
    • Provide any inspection the agent cannot actually perform, or leave that check unverified.

    The current preference is human narration. At 50–100 distinct 30–60 second scripts, speaking alone takes roughly 25–100 minutes, before retakes.

    What is not running today: a background batch manager that keeps generating, scheduling, collecting metrics and improving guidance by itself. There is no automatic vision/audio judge establishing every standard, and no production benchmark proving 100 compliant videos per day. Human decision checkpoints are repository instructions followed by agents, with decisions retained in briefs or review sessions. The local publishing gate checks export compliance; direct provider or browser actions can bypass it, so instructions require the gated path.

    Publishing and analytics access are configured. Provider draft operations and the local gate have been tested; live video publishing has not yet been exercised through this workflow. A later standard change also does not automatically cancel an already scheduled provider post.

    05 / Where a new agent goes next

    The assignment selects the route.

    “Make a batch of SAT videos.”

    Read AGENTS.md and load LOGIC.md first. Prepare a concrete viewer-experience and payoff recommendation for your approval, then read the README model-allocation policy and production status, QUALITY.md, STYLE.md and the campaign strategy. Once you approve the intent and batch scope and resume production, assign Sol/Opus producers and an independent Fable/Astra reviewer. Choose exact source dossiers inside the selected channel, write complete briefs and recipes, then follow production, narration, export review and gated publishing. The active slate supplies candidate subject matter; it does not override source-modeled baseline selection.

    “Review performance and improve the next batch.”

    Read LOGIC.md first. Assign a Fable/Astra reviewer; read the campaign strategy and README observation workflow. Fetch and preserve analytics, link posts to exact reviews, generate learning evidence, analyze only eligible creative outcomes, inspect the corresponding videos, then run backpass scan and backpass to prepare proposals. Present the conclusions, evidence, uncertainty and exact edits to you. Apply only your approved changes through native proposal review; retain rejected or pending decisions. Keep excluded outcomes available for execution diagnosis.

    “I just want to record my voice.”

    The agent starts npm run record and opens the local recorder in the dedicated Chrome profile. You choose a script, record, stop, listen and save. Alignment can run while you move to the next script. A mismatched take is retained for review and does not replace the prior narration.
